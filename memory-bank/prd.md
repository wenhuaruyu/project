# 民宿微信小程序 PRD（桂花主题）

## 一、产品定位

### 1. 产品目标
- 面向已预订民宿的客户，提供从入住前到离店后的“一站式服务”。
- 以“信息清晰、操作简单、服务完整”为核心，降低客户咨询成本与店主沟通压力。
- 通过伴手礼与文创产品预定，形成服务增值与收入补充。

### 2. 目标用户
- **核心用户**：已预订该民宿的客户（入住前、入住中、离店前）。
- **运营用户**：民宿店主或运营人员（维护信息、管理商品与订单）。

### 3. 设计定位（桂花主题）
- 视觉关键词：清淡、优雅、温暖、自然。
- 风格原则：低干扰阅读、重点信息突出、核心功能 3 步内可达。
- 建议色板：
  - 主色：`#D9A441`（桂花金）
  - 辅色：`#F8F3E8`（米白）
  - 点缀：`#7C9A6D`（桂叶绿）
  - 文本：`#2F2A26`（墨灰）

## 二、核心功能列表

### 功能 1：入住助手（基础信息 + 客户登记）
- 展示民宿关键信息：Wi-Fi、地址、联系方式、入住须知。
- 提供快捷动作：一键复制 Wi-Fi、一键导航、一键拨号。
- 客户信息登记：姓名、手机号、证件信息（按合规配置）、预计到店时间、特殊需求。
- 表单校验与异常提示：格式校验、必填校验、网络失败重试。

### 功能 2：旅游攻略
- 展示周边景点、交通方式、建议游玩时长、注意事项。
- 支持搜索、分类筛选、距离/热度排序。
- 支持一键导航与地址复制。

### 功能 3：伴手礼预定
- 提供本地伴手礼与自创文创商品的推荐、浏览与详情介绍。
- 支持规格选择、下单、支付、订单查询。
- 订单状态可追踪：待支付、已支付、已备货、已完成、已取消。
- 库存与支付异常处理：库存不足拦截、超时未支付自动取消。

### 支撑能力（后台）
- 民宿信息管理：Wi-Fi、地址、联系方式、入住须知。
- 攻略内容管理：新增、编辑、上下架、排序。
- 商品与订单管理：价格、库存、订单处理、核销记录。

## 三、用户使用流程

### 流程 A：入住前（信息确认与登记）
1. 用户打开小程序并完成身份校验（预订手机号/订单号）。
2. 进入首页查看入住信息（Wi-Fi、地址、联系方式、入住须知）。
3. 用户填写并提交客户登记信息。
4. 系统提示登记成功，店主后台可查看。

### 流程 B：入住中（游玩决策）
1. 用户进入“旅游攻略”页面。
2. 按兴趣或距离筛选景点。
3. 查看详情（交通方式、时长、注意事项）。
4. 点击导航前往景点。

### 流程 C：离店前（伴手礼购买）
1. 用户进入“伴手礼”页面，浏览推荐商品。
2. 选择规格与数量，提交订单。
3. 完成微信支付。
4. 在“我的订单”查看处理状态，按提示自提或配送。

## 四、版本边界（V1）

### 本期必须实现
- 入住助手、旅游攻略、伴手礼预定三大核心模块闭环可用。
- 支持基础后台配置与订单处理。

### 本期暂不实现
- 用户社区（发帖/评论）。
- 复杂会员积分体系。
- 独立 App 端。
